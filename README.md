# Лабораторна робота №3
## Метод найменших квадратів. Алгебраїчні многочлени найкращого квадратичного наближення

### Опис
Програма реалізує метод найменших квадратів для побудови апроксимуючого
алгебраїчного многочлена степеня m (m = 1..10) за табличними даними
середньомісячних температур.

### Функціонал
- Зчитування даних з CSV-файлу `data_lab3.csv`
- Формування матриці B та вектора C
- Розв'язання СЛАР методом Гауса з вибором головного елемента по стовпцях
- Обчислення дисперсії для кожного степеня m
- Вибір оптимального степеня полінома
- Побудова графіків апроксимації, похибки, залежності дисперсії
- Прогноз температури на наступні 3 місяці

### Запуск
```bash
python lab3.py
